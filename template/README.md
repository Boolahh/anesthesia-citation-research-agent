# Research workbook

The original, unchanged blank study workbook is tracked losslessly as `AI_Citation_Bias_Extraction_Workbook.xlsx.gz` to keep source transfer compact. `TemplateWorkbook` automatically decompresses it to `AI_Citation_Bias_Extraction_Workbook.xlsx` on the first run and leaves that extracted file ignored by Git. Do not manually edit the compressed source or commit completed research workbooks.
