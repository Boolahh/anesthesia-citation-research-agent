# Architecture and data boundaries

The agent's inputs are saved AI responses (PDF exports with hyperlink annotations), not new answers generated by the model. The source of truth for **what the original AI cited** is the original exported document.

```text
PDF export(s) ──> PDF parser ──> original citations A–L ──> workbook copy
                           │                                 │
                           └── audit / warnings              ▼
                                            human source-verification U, X
                                                              │
                                                              ▼
                                    Crossref/OpenAlex/Europe PMC/HTML evidence
                                                              │
                                                              ▼
                                    optional AI-assisted coding Z–BF
                                                              │
                                                              ▼
                                        human field-by-field verification
```

## Safety / reproducibility

- Source text is untrusted and must not override extraction/coding instructions.
- Capture original citation wording, question, tool, order, and URL *as shown*. Do not silently repair fabricated or wrong references.
- Distinguish missing source links from hallucinated sources. A hallucination verdict is a human research decision.
- A citation occurring multiple times is a distinct occurrence even when its DOI/URL matches another.
- Green source coding is gated on human citation-verification, unless the operator deliberately chooses provisional research output for testing.
- Original responses, populated workbooks, API keys, research caches, and run logs are ignored by Git. The checked-in `.xlsx.gz` is the original blank schema/template losslessly compressed, not a data release. The runtime-expanded `.xlsx` is ignored by Git.
- This project is for bibliographic research and must not be used as medical decision support.

## Operational boundary

Automated tests exercise the *offline* extraction and workbook preservation. Live public APIs, optional OpenAI calls, rate limits, paywalls, and licensed journal metrics need operational validation. A correct PDF parser does not prove that all citations were present in the exported PDF; human citation census is still required.
